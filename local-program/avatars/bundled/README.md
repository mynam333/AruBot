Only the original Idle, Run, Jump and Hit PNG sheets for Mask Dude,
Ninja Frog, Pink Man and Virtual Guy are bundled. Image bytes are unmodified.
Each cell is 32 x 32 pixels. Playback follows the author's 20 FPS setting.
Run is used for horizontal movement and mirrored for left-facing movement.
The pack does not include dedicated dance, wave or sit sheets; those actions
use the idle image with the application's motion effects.

These third-party assets are not AruBot-created artwork. The original hand-drawn
robot defaults have been removed. Attribution is not required by CC0 but is
included here for provenance. See CC0-1.0.txt for the license text.
