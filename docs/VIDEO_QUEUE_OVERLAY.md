# 신청곡 리스트 오버레이

영상 후원 페이지의 **영상 후원 · BGM 주소**에서 세 주소를 각각 복사할 수 있습니다.

- **영상 후원 플레이어 주소**: 기존 영상 후원 OBS 브라우저 소스입니다.
- **BGM 플레이어 주소**: 스트리머 화면에 표시하는 기존 BGM 플레이어입니다. YouTube 플레이어를 숨기는 용도로 사용하지 않습니다.
- **신청곡 리스트 주소**: 현재 곡과 영상 후원·BGM 신청곡의 실제 재생 순서를 표시하는 별도 OBS 브라우저 소스입니다. 소리는 재생하지 않습니다.

각 주소는 기본적으로 흐리게 표시되며 클릭하거나 눈 아이콘을 누른 경우에만 표시됩니다. 다시 누르면 숨겨집니다. 복사 버튼은 주소를 노출하지 않고 복사합니다. **주소 새로 만들기**를 누르면 세 주소가 함께 변경되므로 기존 브라우저 소스의 주소도 교체해야 합니다.

## 표시 방식

- OBS 소스 크기에 맞춰 표시 행 수가 조정됩니다. 시작 크기는 **460 × 640**을 권장합니다.
- 현재 곡, 일시정지, 대기 음악, BGM 플레이어 대기를 구분합니다.
- 영상 후원에 의해 중단된 BGM은 실제 순서의 대기열에 남고 `이어 재생`으로 표시됩니다.
- 세로 공간을 벗어난 곡은 `… +n곡`으로 표시됩니다.
- 긴 제목은 시작점에서 잠시 머문 뒤 뒤쪽 내용을 보여 주고, 끝에서 멈췄다가 즉시 처음으로 돌아갑니다. 운영체제의 동작 줄이기가 켜져 있으면 제목 애니메이션은 꺼집니다.
- 목록은 2초 간격으로 갱신됩니다. 연결 오류가 나면 기존 목록을 유지하고 재연결을 계속 시도합니다. 오류가 반복되면 재시도 간격은 최대 30초까지 늘어납니다.

## 동작 경계

`/viewer/requests/[viewerToken]`은 `/api/video-donation/queue-display`를 읽기만 합니다. 플레이어 연결 수, BGM 재생 권한, 스킵·종료 처리에는 참여하지 않습니다. 목록에 표시할 제목·신청자 닉네임·종류·썸네일·재생 시간만 반환하며 내부 사용자 ID나 포인트 비용은 포함하지 않습니다. 갱신은 봇 서버만 조회하므로 별도의 YouTube API 호출을 만들지 않습니다.

주소는 비공개로 취급해야 합니다. 기존 플레이어와 동일한 비밀 토큰을 사용하며, 토큰 재발급 후에는 이전 목록 주소도 무효화됩니다.

## 시청자 신청곡 페이지

시청자 채널 홈과 공통 메뉴의 **신청곡**에서 `/c/[channelUid]/requests` 페이지로 이동합니다. 로그인이나 OBS 비밀 주소 없이 확인할 수 있습니다.

- 현재 곡과 영상 후원·BGM 대기열을 실제 재생 순서대로 표시합니다.
- 제목, 신청자 닉네임, 신청 길이, 신청 구간, 원본 영상 바로가기를 제공합니다. 현재 곡은 재생 진행과 남은 시간도 표시합니다.
- 신청 길이는 원본 전체 길이가 아니라 신청한 구간의 재생 시간입니다. 길이가 아직 확인되지 않은 항목은 `확인 중`으로 표시합니다.
- 대기열은 20개씩 페이지를 넘겨 전체 목록을 볼 수 있습니다. 재생이 진행되어 마지막 페이지가 사라지면 유효한 페이지로 이동합니다.
- 화면이 열려 있는 동안 5초 간격으로 갱신하며, 다른 탭으로 이동하면 자동 조회를 줄입니다. 연결 오류가 나면 마지막 목록을 유지하고 계속 재시도합니다.

공개 조회는 `/api/public/:uid/requests`를 사용합니다. 채널 소유자를 검증한 뒤 해당 봇의 목록만 읽으며, 재생 제어와 플레이어 연결 등록은 수행하지 않습니다. 영상 링크는 지원 플랫폼의 공개 시청 주소로 재구성하므로 OBS 토큰이나 서명된 재생 URL이 공개되지 않습니다.
