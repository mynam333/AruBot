# 로컬 아바타 기획 및 출시 기준

## 목표와 범위

치지직 시청자가 채팅하면 방송 하단에 캐릭터가 등장하고, 스트리머가 로컬 프로그램에서 이미지와 상호작용을 편집한다. 웹사이트 UI는 변경하지 않는다. 캐릭터, 설정, 시청자 선택과 게임 기록은 방송 PC에만 저장한다. 서버는 기존 로컬 프로그램 인증으로 해당 방송의 이벤트만 중계한다.

"완벽함"은 검증할 수 있는 출시 기준으로 대체한다. 구현 완료, 자동 검사 통과, 실제 치지직/OBS 방송 검증, 서명된 설치 파일 배포는 서로 다른 단계다. 마지막 두 단계 없이 상용 운영 검증 완료라고 표시하지 않는다.

## 참고와 비교

- Stream Avatars 공식 제품 소개: https://store.steampowered.com/app/665300/Stream_Avatars/
- 명령어: https://docs.streamavatars.com/stream-avatars/commands
- 아바타 제작: https://docs.streamavatars.com/stream-avatars/content-creating/creating-avatars
- 스크립트: https://docs.streamavatars.com/lua-scripting-api/introduction

현재 Stream Avatars도 치지직, 장비, 미니게임, 시청자 선택, Lua 확장을 지원한다. 따라서 '치지직 지원' 자체를 우위라고 주장하지 않는다. PNG 스프라이트 시트 제작 대신 GIF/WebP/일반 이미지부터 바로 시작할 수 있고, 아루봇 인증 재사용과 한국어 설정, 코딩 없는 복합 반응, 미리보기와 운영 제어의 통합을 차별점으로 삼는다. 경쟁 제품의 에셋이나 코드는 복제하지 않는다.

이번 기능은 Steam Workshop, Lua 실행, 장비 상점, 유료 재화, 시청자 웹 편집기를 복제하는 프로젝트가 아니다. 로컬 아바타 운영이라는 범위에서 완결성을 검증한다. 기존 아루봇 포인트를 로컬에서 차감하거나 환불하지 않는다.

## 구현 계약

### 로컬 화면

기존 메뉴에 **아바타** 한 항목을 추가한다. 시작/일시정지, OBS 주소 복사, 미리보기, 캐릭터 목록과 상태 이미지 편집, 장면 설정, 상호작용 규칙 편집, 참여자 관리, 게임 운영, 테스트 채팅, 백업/복원을 제공한다. 이미지 삭제와 복원, 개인정보 초기화에는 확인 절차가 있다. 이미지 파일은 원본을 로컬 폴더로 복사하므로 원본 이동 후에도 재생된다.

### 캐릭터와 장면

기본 캐릭터는 Pixel Frog의 [Pixel Adventure](https://pixelfrog-assets.itch.io/pixel-adventure-1) 무료 CC0 팩 4종이다. 원본 대기/이동/점프/피격 스프라이트를 20 FPS로 재생하고 좌우 이동은 방향 반전으로 표현한다. 자체 제작 로봇은 제거한다. 출처, 원본 체크섬과 라이선스를 설치 파일에 포함한다. 전용 춤/인사/앉기 이미지는 이 팩에 없으므로 해당 동작은 대기 이미지에 움직임 효과를 적용한다.

PNG/JPEG/GIF/WebP를 등록하며 애니메이션 원본은 그대로 보존한다. 스프라이트 시트는 열/행/프레임 수/FPS로 설정한다. 상태 이미지가 없으면 기본 이미지와 움직임으로 대체한다. 크기, 바닥 위치, 걷기 속도, 최대 인원, 비활동 퇴장, 이름표, 말풍선, 대상 상호작용을 설정한다. 방송 해상도에 비례해 동일하게 보인다. 일시정지는 물리/동작/시트 프레임을 정지한다. GIF/WebP 자체의 내부 애니메이션은 브라우저 디코더 특성상 계속 움직인다.

### 채팅과 반응

안정적인 플랫폼 사용자 ID로 구별하고 닉네임 변경은 외형 선택을 초기화하지 않는다. 자동 입장과 명령 입장을 선택한다. 입장/퇴장, 점프, 춤, 인사, 앉기, 좌우 이동, 모이기, 따라가기, 하이파이브, 밀기, 캐릭터 선택, 이름표 색상과 크기를 지원한다. 이름이 중복되는 대상은 임의 선택하지 않는다.

규칙은 명령/첫 입장/일반 채팅/후원/구독 트리거, 명령 별칭, 사용 권한, 재사용 대기 시간, 후원 최소값, 최대 8개의 순차 동작으로 구성한다. 동작은 선택형이며 대기, 이동, 점프, 춤, 인사, 앉기, 크기, 말풍선, 모이기, 따라가기, 하이파이브, 밀기로 제한한다. 반복/JavaScript/Lua/정규식/파일 명령은 실행하지 않는다. 기존 아루봇 채팅 명령은 가로채지 않는다.

명시적인 채팅 명령을 일반 채팅 반응보다 우선한다. 동일 조건에 여러 규칙이 있으면 목록의 첫 실행 가능한 규칙을 사용한다. 새 동작은 같은 시청자의 이전 순차 동작을 대체한다.

### 게임과 운영

관리자가 시작하는 제한 시간 달리기와 공동 응원 목표를 제공한다. 게임 시작 전 참가자를 고정하고 중도 퇴장/차단에 대응하며 결과는 화면에 표시한다. 게임은 방송 포인트에 영향을 주지 않는다. 테스트 시청자는 실제 시청자 기록과 분리하고 한 번에 제거할 수 있다. 전체 일시정지, 화면 비우기, 사용자 차단/해제/기록 삭제를 지원한다.

### 달리기, 공중부양과 편집 테스트 (2026-10-11)

- `!달리기 5`, `!run 5`: 5초 동안 빠르게 이동한다. 속도는 일반 명령 걷기의 1.5~6배, 벽에서는 방향을 바꾼다. 전용 달리기 이미지가 없으면 걷기 시트를 빠르게 재생한다.
- `!부양 8`, `!공중부양 8`, `!float 8`: 전체 8초 안에 부드럽게 상승하고 제자리에서 떠 있다가 착지한다. 높이는 30~500px이며 상승/하강은 각각 전체 시간의 25%, 최대 1.2초다. 별도 부양 이미지도 지정할 수 있다.
- 동작 시간은 0.1~120초다. 규칙의 '채팅 숫자로 시간 지정'을 켜면 명령 뒤 숫자가 각 단계의 시간을 대체한다. 숫자가 없으면 저장한 시간을 사용한다. 기본 두 명령은 이 옵션이 켜져 있다.
- 기존 v1 설정에는 두 기본 반응을 한 번만 추가한다. 같은 별칭을 사용 중인 사용자 반응은 덮어쓰지 않으며, 업데이트 후 삭제한 기본 반응을 다시 생성하지 않는다.
- 테스트 요청은 편집 중인 전체 설정을 검증한 뒤 독립적인 메모리 엔진에 적용한다. 실제 방송이 중지/일시정지 상태여도 테스트할 수 있다. 같은 테스트 참여자의 이전 동작/명령 쿨다운을 초기화해 수정 직후 재실행한다.
- 방송 출력과 편집 테스트는 물리 세계, 웹소켓 프레임, 게임과 기록이 분리된다. 테스트는 OBS나 저장 파일에 반영하지 않는다. 실제 반영은 '설정 저장'으로 수행한다. 방송 시작/일시정지 버튼은 미저장 편집을 함께 저장하지 않는다.
- 캐릭터/반응 편집 화면에 직접 테스트 버튼을 제공한다. 게임 테스트, 테스트 일시정지/초기화와 입력값 유지를 지원한다. 미리보기는 높게 떠오른 캐릭터가 잘리지 않도록 프레임을 맞추며 OBS 출력의 배율은 바꾸지 않는다.
- 새 반응/게임은 이전 추적, 접촉과 부양 상태를 정리한다. 대기는 이동을 멈추고 말풍선은 설정 시간에 맞춰 사라진다. 일시정지는 부양 시간과 쿨다운을 함께 정지한다.

### 통신과 데이터

OBS HTTP/WS는 `127.0.0.1`에만 바인딩한다. 출력 주소에는 독립적인 랜덤 키만 사용하고 아루봇 인증 토큰은 포함하지 않는다. OBS 연결은 읽기 전용이며 제어는 Electron IPC로만 수행한다. 서버 연결 중단 시 기존 캐릭터는 유지하고 신규 채팅 수신 상태를 로컬 화면에 표시한다. 재접속 시 끊긴 동안의 명령을 몰아서 재생하지 않는다. 사용자 기록은 채널별 구분, 상한 및 보관 기한으로 관리한다.

## 검증 및 출시 판정

- 기능: 설정 저장/재시작, 이미지와 상태 변경, 애니메이션, 별칭과 권한, 대상/순차 반응, 게임 결과, 일시정지, 백업 왕복.
- 장애: 중복 이벤트, 느린/끊긴 OBS, 서버 재접속, 잘못된 이미지/백업, 저장 오류, 포트 충돌, 채널 전환.
- 보안: 경로 탈출, 외부 웹 출처, 잘못된 출력 키, 채팅 HTML, 데이터 상한, 이벤트 위조와 다른 채널 격리.
- 성능: 제한 인원 물리 연산과 스냅샷 부하, 장시간 동작의 메모리 상한, 저사양 방송 PC에서 CPU/GPU 확인.
- UI: 실제 로컬 화면에서 등록-설정-테스트-미리보기 흐름과 좁은 창, 오류/빈 상태를 확인.
- 배포: 패키징 의존성 포함 확인, Windows 설치/업데이트, 실제 치지직 토큰과 OBS 브라우저 재시작을 운영자가 확인한 뒤 상용 배포 승인.

구현 또는 검증에서 미충족 항목이 나오면 해당 항목을 보완하고 다시 검사한다. 실제 계정/방송/서명이 필요한 검증을 테스트 대역으로 통과한 것처럼 취급하지 않는다.
