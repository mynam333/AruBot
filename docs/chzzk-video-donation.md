# 치지직 영상후원 연동

## 설정

`영상 후원 > 영상 후원 설정 > 치지직 영상후원 연동`에 치지직 스튜디오의 **영상후원 브라우저 소스 URL**을 입력합니다. 일반 채널 URL이나 후원 페이지 URL이 아닙니다.

- **영상·BGM 일시정지**: 별도 치지직 영상후원 소스를 사용하는 구성입니다. 치지직 후원 수신 시 아루봇 영상, 신청 BGM, 대기 음악을 일시정지합니다. 종료 구간이 지나거나 치지직 스킵 이벤트가 오면 재개합니다. 직접 일시정지해 둔 항목은 계속 정지 상태를 유지합니다.
- **아루봇 대기열에 추가**: 치지직 후원을 기존 영상 후원 대기열에 등록합니다. YouTube 영상과 치지직 클립을 지원하며 포인트를 다시 차감하지 않습니다. 기존 영상은 순서대로 재생하고, 신청 BGM은 기존 영상 후원 우선 규칙에 따라 중단 후 이어 재생합니다.
- **둘 다 켬**: 대기열 통합을 우선합니다. 아루봇에서 재생하는 치지직 후원 때문에 아루봇 자체가 멈추지 않습니다.
- **둘 다 끔**: 연결하지 않습니다. 저장한 URL은 다음 사용을 위해 유지됩니다.

통합 대기열 모드에서는 기존 치지직 영상후원 브라우저 소스를 OBS에서 제거해야 이중 재생을 피할 수 있습니다. 이 기능이 사용자의 OBS 소스를 자동으로 삭제하지는 않습니다.

URL은 알림을 구독할 수 있는 비밀 주소입니다. 영상 후원 설정 응답과 오버레이에는 원문을 전달하지 않습니다. 홈페이지에서는 새 주소로 교체하거나 저장된 주소를 삭제할 수 있습니다. 별도 확장 프로그램은 필요하지 않습니다.

## 처리 및 복구

- 치지직 영상후원 알림 세션에 연결하고 끊어지면 지수 백오프로 재연결합니다.
- 서버 재시작과 설정 변경은 저장된 설정을 주기적으로 다시 확인하여 복구합니다.
- 각 서버의 알림 구독은 독립적이지만, 대기열 등록은 DB의 후원 ID 기반 멱등 키로 중복을 방지합니다.
- 가져온 대기 항목은 기존 durable runtime jobs에 저장합니다. 처리 중인 항목의 임대를 갱신하여 다른 서버가 재생 중 항목을 다시 가져가지 않도록 합니다.
- 치지직 `donationControl.stopVideo`는 같은 후원 ID의 대기·재생 항목에만 적용합니다. 아루봇 스킵과 삭제도 치지직 종료 알림을 보냅니다.
- 치지직에서 알림만 재생하는 `ALERT_PLAY`, 재생하지 않는 `IGNORE` 이벤트는 영상으로 자동 전환하지 않습니다.

## 검증 경계

치지직 웹 알림 프로토콜은 공식 Open API와 별개이며 변경될 수 있습니다. 구현 시 확인한 실제 웹 클라이언트의 `donation`, `donationControl`, `donationSetting`, 세션 URL 및 재생/종료 알림 경로를 사용합니다.

**일시정지만 사용하는 모드의 자연 종료 시점은 수신한 영상 구간과 알림 지연을 바탕으로 추정합니다.** 별도 OBS 치지직 소스의 실제 버퍼링, 수동 일시정지, 알림 사운드 길이까지 서버가 관측할 수는 없습니다. 정확한 재생 완료·스킵 기준으로 한 대기열을 관리하려면 통합 대기열 모드를 사용합니다. 통합 모드는 아루봇 플레이어의 기존 재생 완료 보고와 서버 타이머를 사용합니다.

배포 후 본인 치지직 링크로 연결 상태를 확인하고 치지직 테스트 영상후원, 실제 후원, 스킵, OBS 재연결을 확인해야 합니다. 테스트 통과는 실제 계정 연결이나 OBS 재생 확인을 대체하지 않습니다.
