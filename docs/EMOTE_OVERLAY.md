# 이모티콘 오버레이 설계

## 사용자 흐름

관리 화면 `/emote-overlay`에서 기능을 켜고 플랫폼과 효과를 선택한다. 변경 중인 설정은 같은 렌더러를 사용하는 미리보기에 즉시 반영되며, 저장하면 OBS에 적용된다. OBS 주소는 클릭해야 표시되고 복사 및 주소 재발급을 지원한다. 로컬 미리보기와 실제 OBS 전송 테스트는 구분한다.

OBS는 투명 배경 `/viewer/emotes/<token>`으로 실행한다. 인증 토큰은 이모티콘 표시 전용이며 관리 API 접근에 사용할 수 없다. 재발급하면 이전 주소는 폐기한다. 채팅 원문과 시청자 계정 정보는 오버레이에 전송하지 않는다.

## 효과

1. 풍선 이동: 화면 가장자리에서 반대 방향으로 이동하며 완만한 사인 곡선과 독립적인 회전, 시작/종료 페이드 적용. 방향·흔들림 크기·주기·회전 설정.
2. 탄성 낙하: 상단 분산 생성, 중력·바닥/벽 충돌·마찰·개별 탄성 적용. 수명 후반에는 개별 충돌을 해제해 아래로 빠지면서 소멸. 개체 간 충돌 선택 가능.
3. 스티커: 지정 영역 안 무작위 위치에 배치. 등장/퇴장 각각 페이드, 팝, 바운스, 스핀, 글리치, 블러, 디졸브, 더스트, 드롭, 폭발, 압축 지원. 방향·전환 시간·기울기·파편 개수 설정.
4. 발사: 8개 가장자리/모서리, 무작위, 사용자 지정 좌표. 초기 속도·각도·분산·중력으로 계산한 포물선, 회전과 잔상. 속도가 바뀌면 실제 도달 높이와 거리가 달라진다.
5. 랜덤 혼합: 위 4종 중 개체마다 선택. 전환해도 각 효과의 설정은 보존한다.

공통 크기·불투명도·수명·이동 속도·페이드·변동 폭·표시 영역을 설정한다. 물리 연산은 기존 Matter.js를 사용하고, 이미지/GIF/WebP 원본 애니메이션은 DOM 이미지로 유지한다. 랜덤 편차는 생성 시 고정하여 프레임마다 떨리지 않게 한다. 접근성용 관리자 미리보기 일시정지와 화면 비우기를 제공한다.

## 안전·복구

- 효과 설정과 이벤트를 채널 소유자별로 분리하고 기존 봇 관리자 세부 권한에 편입.
- 메시지당·초당·동시 표시·사용자 쿨다운 제한. 밀린 이벤트를 무한 적재하지 않고 오래된 이벤트부터 버린다.
- 서버는 짧은 수명의 이벤트만 저장. 복수 API 프로세스에서도 동일 DB 커서로 누락을 보완한다.
- 재연결은 횟수 제한 없이 지수 지연하며, 첫 연결 시 예전 채팅을 몰아서 재생하지 않는다.
- 비활성화·화면 비우기·토큰 회전으로 대기 이벤트도 폐기. GIF 이미지 실패, 탭 비활성화, 창 크기 변경, 긴 프레임 지연을 처리한다.
- 테스트는 운영 채팅에 메시지를 보내지 않는다. 배포 후 실제 플랫폼 채팅과 OBS 확인은 별도로 수행한다.

## 운영 설정

- 기본 상태는 비활성화다. 기존 채팅 봇 연결을 사용하므로 표시할 플랫폼이 먼저 연결되어 있어야 한다.
- 관리 권한은 `emotes:read`, `emotes:write`로 분리한다. 전체 권한과 사이트 관리자는 기존 정책을 따른다.
- 저장 모델은 `028_emote_overlay.sql`이며 첫 접근 시 적용한다. 설정은 소유자별 저장, OBS 주소는 이 기능 전용 토큰이다.
- OBS 브라우저 소스 크기는 방송 캔버스와 동일하게 설정한다. 이미지 크기는 높이 1080 기준으로 비례한다.
- 일반 유니코드 문자나 프로필/배지 이미지는 추정하여 표시하지 않는다. 플랫폼이 채팅 메시지에 포함한 이모티콘 이미지 메타데이터만 사용한다.
- 이미지가 만료되거나 해당 CDN에서 외부 표시를 차단하면 해당 개체를 제거한다. 서버가 임의 이미지 주소를 대신 가져오지는 않는다.
- 이벤트는 8초 이내인 것만 새로 전달하고, 저장된 이벤트는 30초 후 정리한다. 페이지 최초 실행에서는 지난 채팅을 재생하지 않는다.
- SSE가 실패하면 HTTP 조회로 보완하며 연결을 계속 재시도한다. 서버 간 누락 보완 주기는 1.5초다.
- 장기 연결에는 별도 전역/네트워크 연결 한도를 적용하여 일반 API 요청 처리 공간을 유지한다.

## 검증 명령

`npm run test:emotes`는 설정·이미지 추출·저장/제한·연결 복구·효과 엔진을 검사한다. `npm test`에는 기존 채팅 수신부와 권한 통합 검사가 포함된다. 관리 화면과 OBS 화면의 시각 검사는 운영 API에 쓰지 않는 격리된 응답으로 수행한다.

실제 운영 PostgreSQL 마이그레이션, 각 플랫폼의 실시간 채팅, OBS CEF에서의 외부 CDN/GIF 표시는 배포 환경에서 별도로 확인해야 한다. 자동화 테스트나 Chrome 검사는 이 항목들의 실측을 대신하지 않는다.

### 구현 후 확인 결과 (2026-10-12)

- 전용 Node 테스트 85개 통과. 실제 Express SSE 연결/종료, 복수 인스턴스 조회 보완, 커서 중복 방지, 권한, 제한과 저장 충돌 포함.
- 전체 Jest 1,383개 통과, 기존 환경 의존 테스트 5개 제외.
- 프로덕션 빌드와 TypeScript 검사 성공. 전체 ESLint 오류 없음 (기존 노래책 파일의 Fast Refresh 경고 1건).
- 격리 API + Chrome에서 4종 효과와 랜덤 모드, 11종 스티커 등장/소멸, 미리보기 일시정지/비우기, 설정 저장/충돌, 읽기 전용 관리, 주소 클릭 표시, OBS 중복 방지/화면 비우기 확인.
- 데스크톱 1440px 및 모바일 390px/320px 화면 확인. 물리 연산은 30/60/120Hz 비교, 개체/파편/잔상 상한과 수명 종료 후 자원 해제 검사.
