# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and Purpose

AruBot helps streamers and delegated bot managers operate interactive broadcasts.
Viewers browse a streamer's songbook and submit song requests. Streamers mark
requests as singing or completed in the existing songbook management page.

## Operating Context

Broadcast graphics run in transparent OBS browser sources. Management stays in
the website. Broadcast graphics must not obscure the main broadcast unnecessarily.
Songbook graphics need independently saved landscape and portrait arrangements.

## Constraints

Keep existing songbook behavior, saved data, and delegated permissions. Overlay
links are read-only capabilities, never editing credentials. Broadcast displays
must recover automatically after backend restarts. Sample preview content must
never enter real request queues.
